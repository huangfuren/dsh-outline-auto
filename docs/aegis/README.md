# Aegis Workspace — dsh-outline-kb

本目录是 `dsh-outline-kb` 插件的 Aegis 项目工作区，用于承载跨会话的设计/规格/基线记录。

## 结构

- `INDEX.md` — 文档索引（spec / plan / baseline / adr）
- `BASELINE-GOVERNANCE.md` — 基线治理约定（需求/架构双基线）
- `baseline/` — 基线快照（证据，非权威）
- `specs/` — 已批准的设计规格文档
- `plans/` — 实施计划（如需要）

## 约定

- 权威来源优先：DSH 官方文档与源码 > 本工作区记录
- 本工作区只记录本项目（dsh-outline-kb）自身的决策与基线，不记录 DSH 内部事项
